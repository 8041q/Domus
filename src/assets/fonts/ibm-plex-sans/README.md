IBM Plex Sans Regular (400), Medium (500), SemiBold (600) and Bold (700),
served locally for the interface and canvas labels. PDF reports use Regular
and Medium.

Source: https://fonts.google.com/specimen/IBM+Plex+Sans (Google Fonts v23).
The original font files are unmodified. The SIL Open Font License is included
at `public/fonts/ibm-plex-sans/OFL.txt` and copied into production builds.
